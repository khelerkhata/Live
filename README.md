# 🏏 Khelar Khata - GitHub Pages Live Web Viewer

A professional, zero-cost, public live cricket stream & broadcast overlay viewer designed to be deployed directly to **GitHub Pages**.

---

## 🔒 নিরাপত্তা ও সিকিউরিটি নিশ্চয়তা (Zero-Leak Guarantee)

আপনার প্রধান উদ্বেগের বিষয় ছিল: **"যেহেতু এটি গিটহাবে আপলোড করা হবে সেহেতু সমস্ত কোড উন্মুক্ত থাকবে, এর জন্য নিরাপত্তা বা সিকিউরিটি যাতে কোনো কিছু পাস/লিক না হয়।"**

### কেন এই সিস্টেমটি সম্পূর্ণ নিরাপদ?
1. **কোনো সিক্রেট/অ্যাডমিন কি (Admin Private Keys) নেই:**
   - ওয়েব ভিউয়ারে শুধুমাত্র Firebase Web Client SDK ব্যবহার করা হয়েছে।
   - Google Firebase-এর আর্কিটেকচার অনুযায়ী `apiKey`, `projectId`, এবং `databaseURL` হলো পাবলিক ক্লায়েন্ট আইডেন্টিফায়ার (Client Identifiers), এগুলো কোনো অ্যাডমিন পাসওয়ার্ড বা গোপন প্রাইভেট কি নয়। পৃথিবীর সব পাবলিক ওয়েব অ্যাপেই এগুলো ফ্রন্টএন্ডে থাকে।
2. **ডাটাবেজ লেভেলে সুরক্ষিত (Firebase Security Rules):**
   - আসল নিরাপত্তা নিশ্চিত হয় ডাটাবেজের নিয়মে (`database.rules.json`)।
   - পাবলিক দর্শকরা শুধুমাত্র খেলা দেখতে পারবে (Read-Only: `.read: true`)।
   - কোনো দর্শক বা হ্যাকার স্কোর পরিবর্তন, ডিলিট বা ওভারলে পাঠাতে পারবে না—কারণ রাইট পারমিশন শুধুমাত্র স্কোরার অ্যাপের অনুমোদিত লগইন ইউজারের জন্য সুরক্ষিত (`.write: "auth != null && ..."`).
3. **স্কোরিং ও কন্ট্রোল শুধুমাত্র অ্যান্ড্রয়েড অ্যাপে:**
   - ব্রডকাস্ট ওভারলে ট্রিগার বা স্কোর আপডেট করার কোনো বাটন বা ফাংশন ওয়েবসাইটে রাখা হয়নি। ওয়েবসাইটটি সম্পূর্ণ রিড-অনলি প্লেয়ার।

## 🚀 গিটহাব পেজেস-এ লাইভ করার সহজ নিয়ম (Step-by-Step Guide)

### ধাপ ১: গিটহাবে রিপোজিটরি তৈরি
1. আপনার GitHub একাউন্টে প্রবেশ করে **New Repository**-তে ক্লিক করুন।
2. রিপোজিটরির নাম দিন (যেমন: `khelar-khata-live` বা `cricket-live`).
3. পাবলিক (Public) সিলেক্ট করে রিপোজিটরি তৈরি করুন।

### ধাপ ২: ফাইলগুলো আপলোড করুন
এই `web-viewer` ফোল্ডারের ফাইলগুলো আপনার রিপোজিটরিতে আপলোড করুন:
- `index.html`
- `style.css`
- `app.js`

### ধাপ ৩: GitHub Pages চালু করুন (মাত্র ২ ক্লিকে)
1. আপনার GitHub রিপোজিটরির **Settings** ট্যাবে যান।
2. বাম পাশের মেনু থেকে **Pages** অপশনে ক্লিক করুন।
3. **Build and deployment** সেকশনে:
   - Source: **Deploy from a branch**
   - Branch: **main** (বা master), ফোল্ডার: **/ (root)**
4. **Save** বাটনে ক্লিক করুন।

১ মিনিটের মধ্যে GitHub আপনাকে আপনার ওয়েবসাইটের লাইভ লিঙ্ক দিয়ে দেবে, যেমন:
👉 `https://<your-username>.github.io/<your-repo-name>/`

## 📺 দর্শকরা যেভাবে খেলা লাইভ দেখবে

অ্যাপ থেকে ম্যাচ লাইভ শুরু করার পর একটি ৬ ডিজিটের ম্যাচ কোড তৈরি হয় (যেমন: `123456`)।

দর্শকদের ওয়েবসাইটের লিঙ্ক পাঠানোর নিয়ম:
```text
https://<your-username>.github.io/<your-repo-name>/?match=123456
```
(অথবা দর্শকরা ওয়েবসাইটে প্রবেশ করে সরাসরি ৬ ডিজিটের কোডটি ইনপুট করতে পারবে।)

### ওয়েবসাইটে দর্শকরা যা যা দেখতে পাবে:
1. **লাইভ ভিডিও স্ট্রিম:** ইউটিউব লাইভ বা ক্যামেরা স্ট্রিম থাকলে তা স্বয়ংক্রিয়ভাবে ভিডিও প্লেয়ারে চলবে। ভিডিও না থাকলে আধুনিক গ্রাফিকাল স্টেডিয়ামের ব্যাকগ্রাউন্ড দেখাবে।
2. **টিভি ব্রডকাস্ট স্কোর বার (Lower Third):** লাইভ রান, উইকেট, ওভার, স্ট্রাইকার, নন-স্ট্রাইকার, বোলার, চলতি ওভারের বল-বাই-বল ডট ও বাউন্ডারি চিপস এবং রানরেট।
3. **অ্যানিমেটেড সেলিব্রেশন:** চার (4), ছক্কা (6), এবং উইকেটের (W) সময় স্ক্রিনের মাঝে আকর্ষণীয় ব্রডকাস্ট অ্যানিমেশন।
4. **ব্রডকাস্ট ওভারলে কার্ড:** ম্যাচ সামারি, আউট ব্যাটসম্যান কার্ড, টার্গেট ব্যানার, এবং বোলার অ্যানালিসিস কার্ড।
5. **ফুলস্ক্রিন মোড:** মোবাইল, কম্পিউটার বা স্মার্ট টিভিতে ফুলস্ক্রিনে দেখার সুবিধা।

## 🛡️ Firebase Console-এ রুলস সেটআপ করার নিয়ম
নিশ্চিত করুন আপনার Firebase Console-এর Realtime Database -> **Rules** ট্যাবে `database.rules.json`-এর নিয়মগুলো পেস্ট করে **Publish** করা আছে:

```json
{
  "rules": {
    "matches": {
      "$matchCode": {
        ".read": true,
        ".write": "auth != null && (!data.child('meta/ownerUid').exists() || data.child('meta/ownerUid').val() === auth.uid)"
      }
    },
    "matchesIndex": {
      ".read": true,
      "$matchCode": {
        ".write": "auth != null"
      }
    }
  }
}
```
এটি ১০০% নিশ্চিত করবে যে আপনার ডাটাবেজ সম্পূর্ণ সুরক্ষিত এবং নিরাপদ।
